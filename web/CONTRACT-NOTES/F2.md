# F2 หน้าโครงการ · หมายเหตุสัญญา

- "มาแล้ว X/Y คน" ที่ทักษะ: ใช้ `checkedIn/headcount` จาก ProjectDetail.skills (ไม่เรียก /api/needs/:id/stats เพื่อลดจำนวนคำขอ)
- สถานะ "สมัครแล้ว" ของทักษะ: ไม่มีใน ProjectDetail จึงอ่านจาก GET /api/volunteer/needs (ฟิลด์ signedUp) เมื่อล็อกอิน
- ทำเนียบ: ถ้า tier = 0 แสดง "ยังไม่ถึงระดับ"; ledger แถวใช้ `donorLabel ?? payee`
- ปุ่มบริจาค: ใช้ `acceptingDonations` จาก API เป็นหลัก เหตุผลที่ปิดคำนวณฝั่งหน้าเว็บจาก status/fundraisingState/endsAt/supportTypes
- ปุ่มจอง/สมัคร/ยืม/ลงชื่อ แสดงเฉพาะ status=active และไม่ frozen · ฟอร์มแจ้งเบาะแสแสดงเมื่อ active หรือ suspended
- ฟอร์มแจ้งเบาะแสอัปโหลดไฟล์ก่อน (/api/uploads) แล้วส่ง {evidenceUrl, reason}
- ไม่แสดง lat/lng และไม่ใช้ฟิลด์อ่อนไหวใด ๆ
