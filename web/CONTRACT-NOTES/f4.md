# F4 · ข้อสังเกตต่อสัญญา

- `POST /api/payments/mock/pay` ไม่ระบุ shape ตอบกลับชัด: หน้าเว็บไม่พึ่ง body ที่ตอบ แต่เรียก `GET /api/donations/:id` ต่อเพื่ออ่าน amount/tip/fee/payable/net/tier จริง และ `GET /api/projects/:id` เพื่ออ่านยอดโครงการใหม่ (`bars.money.raised`)
- `ProjectDetail.rewardTiers[].tier` ต้องเป็นตัวเลข 1..3 ให้ตรงกับ `donation.tier` เพื่อจับคู่คำอธิบายสิ่งตอบแทน (ถ้าไม่ตรง แสดงเฉพาะ "Tier N")
- ผลรวม "สรุปยอดโดยประมาณ" ก่อนกดยืนยันคำนวณฝั่งเบราว์เซอร์ (ทิป 5% ปัดครึ่งขึ้น) เพื่อดูตัวอย่างเท่านั้น · ค่าจริงหลังกดมาจาก API ทั้งหมด
- นับถอยหลัง QR: อ่าน `/api/now` ครั้งเดียวตอนสร้างรายการ แล้วลดทีละวินาที (ไม่ใช้ Date.now)
- ใบเสร็จและ e-Donation ใช้ `kind`/`edonation` จาก `GET /api/receipts/:donationId`
