# F5 หมายเหตุสัญญา

- หลังสมัคร (/register) เรียก POST /api/auth/login ต่อทันทีเพราะสัญญาไม่ระบุว่า register ตั้งคุกกี้ให้ · ต้นเรื่องที่ไม่มี `next` ไปที่ /kyc
- `next` รับเฉพาะพาธที่ขึ้นต้น `/` และไม่ใช่ `//` กัน open redirect
- ประวัติสั้นใน /account เรียก GET /api/me/donations (A2) และ GET /api/notifications · ถ้า API ไม่ตอบจะแสดงว่าว่าง
- รายการบัญชีทดสอบบน /login เขียนเป็นข้อความคงที่ใน app/login/page.tsx (ไม่มีการกรอกอัตโนมัติ)
- ไม่ได้ใช้ useSearchParams (เลี่ยง Suspense) อ่าน `?next=` จาก window.location ใน useEffect
