# F6 · CONTRACT-NOTES

| ขาดอะไร | F6 ทำอย่างไร |
|---|---|
| รูปทรง response ของ `GET /api/me/loans` และ `GET /api/me/pledges` สัญญาเขียนแค่ `[…]` | หน้า `/loans` `/pledges` อ่านฟิลด์แบบยืดหยุ่น: loan = `id, itemName\|item_name\|contract.itemName, startDate, dueDate, status, returnedAt, projectTitle, terms` · pledge = `id, trackingNo, itemName\|item.name, qty, projectTitle, recipient, received` · ถ้า A4 ใช้ชื่ออื่น ให้เพิ่มชื่อใน helper `pick(...)` ของสองหน้านี้ |
| `/loans` ไม่มีปุ่มสร้างสัญญาให้ยืม (`POST /api/loan-requests/:id/lend`) | หน้าที่มอบหมายมีเฉพาะรายการ+คืน จึงไม่ทำปุ่มให้ยืม (อยู่ในหน้าโครงการของ F2) |
| สถานะ overdue | หน้าเว็บคำนวณเพิ่ม: status `active` และ `dueDate` < วันนี้ (เวลาไทย จาก `/api/now`) แสดง "เกินกำหนด" แม้ API ยังไม่ตั้ง overdue |
| QR เช็กอิน | วาดเป็น SVG จำลองจากโทเคน (ไม่ใช่ QR มาตรฐานที่สแกนจริงได้) · อาสาเช็กอินด้วยโทเคน หรือกล้องเมื่อมี `BarcodeDetector` · ถ้าข้อความที่สแกนมี `token=` จะดึงเฉพาะโทเคนส่งให้ API |
| ปุ่มสมัครงานอาสา | ซ่อนสำหรับบทบาท starter/staff (ที่เห็นปุ่ม QR แทน) ส่วนบทบาทอื่นเห็นปุ่มสมัคร |
| ปุ่มรับงานรับรอง | เปิดให้กดได้เสมอแม้ eligible=false เพื่อให้แสดง `error.message` จากเซิร์ฟเวอร์ตรง ๆ (E48/E49) |
| FR-38 (ลงชื่อสนับสนุน) | อยู่ในหน้าโครงการ `/projects/[id]` ของ F2 ไม่อยู่ในพาธของ F6 |
