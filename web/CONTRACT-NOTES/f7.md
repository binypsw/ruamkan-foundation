# F7 notes
- ปุ่ม "ส่งสิ่งตอบแทนแล้ว" ใน /staff เรียก POST /api/staff/rewards/:id/delivered (body `{}`) ตามสัญญา A5.
- /staff/projects/[id] รับทั้ง UUID และ code (ลิงก์ใช้ code) · response ของ GET staff อ่านได้ทั้งแบบ `{project}` และ ProjectDetail ตรง ๆ
- ปลดระงับ/ปิดโครงการทำได้ในหน้าตรวจ (status active/suspended); ปุ่มปิดแสดงเมื่อ active หรือ suspended, API ตัดสินสิทธิ์จริง (BR-29)
- สถิติ "งวดรอดำเนินการ" นับ milestones status=requested; "โครงการถูกร้องเรียน" นับ projects ใน GET /api/staff/flags
- Badge tone 'warn' ไม่มี CSS ใน globals.css (ใช้สไตล์ badge พื้นฐาน)
