# CONTRACT-NOTES · F8

- สัญญา `GET /api/finance/wallets` ระบุแค่ `{wallets:[…], adminFee, central}` ไม่บอกรูปของสมาชิก `wallets[]` · F8 อ่านแบบยืดหยุ่น: `kind|walletKind`, `projectCode|code|project.code`, `projectTitle|title|project.title`, `balance` · `adminFee`/`central` รับได้ทั้งสตริงเงินและวัตถุ `{balance}` (ถ้าไม่มีจะหาจาก `wallets[]` ที่ kind ตรง) · ถ้า A5 ใช้ชื่อฟิลด์อื่นให้ปรับที่ `normWallet()` ใน `components/f8/FinanceView.tsx`
- ไม่มี endpoint ผู้บริจาค/ใบเสร็จสำหรับ finance ในสัญญา: F8 แสดงคอลัมน์ผู้บริจาค (`donorLabel`) ในสมุดบัญชีเมื่อ API ส่งมา ไม่ได้ทำตารางใบเสร็จแยก
- รายการโครงการในตัวเลือกสมุดบัญชีมาจาก `wallets[]` (ครบทุกสถานะ) ถ้าไม่มีรหัสโครงการจึงถอยไปใช้ `GET /api/projects` (เฉพาะ active)
- สัญญาไม่ระบุว่า ledger `kind` ของ entries เป็น `in|fee|out` — ถือตามตาราง `ledger_entries`
